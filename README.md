# codex-kit

Codex CLI로 몇 시간짜리 업무 과제를 풀 때 쓰는 작업 규칙과 스킬 모음이다. 과제 답, 개인정보, 키는 들어 있지 않다.

## 사용법

작업 폴더에서 실행한다.

```bash
git clone https://github.com/hyeongus2/codex-kit /tmp/kit
bash /tmp/kit/setup.sh
```

그다음 Codex를 다시 켜고(`/quit` → `codex`) `/skills`에 스킬 4개가 보이는지 확인한다.

Codex에게 시켜도 된다: "https://github.com/hyeongus2/codex-kit 를 /tmp/kit에 clone하고, 이 폴더에서 bash /tmp/kit/setup.sh 를 실행해". 네트워크 접근과 `~/.agents` 쓰기 때문에 승인 창이 뜰 수 있다.

## setup.sh가 하는 일

| 대상 | 동작 |
|---|---|
| `~/.agents/skills/` | 스킬 4개 복사. 같은 이름 폴더가 있으면 건너뜀 |
| `./AGENTS.md` | 없으면 복사. 있으면 기존 내용은 두고 맨 뒤에 키트 규칙을 한 번만 덧붙임 |
| `./PLAN.md`, `./DECISIONS.md` | 없을 때만 복사 |
| `./.gitignore` | 없으면 복사. 있으면 빠진 줄만 덧붙임 |

인터넷 접속, sudo, `~/.codex` 수정, 파일 삭제, 덮어쓰기는 하지 않는다. 여러 번 실행해도 결과가 같다.

## 파일

| 경로 | 역할 |
|---|---|
| `AGENTS.md` | Codex가 켜질 때 자동으로 읽는 고정 규칙. 과제 내용은 넣지 않는다 |
| `templates/PLAN.md` | 합의된 요구사항, 진행, 예상 밖 발견, 다음 할 일, 결과와 한계 |
| `templates/DECISIONS.md` | 결정 기록 표: 번호, 시각, 결정, 이유, 버린 대안, 근거 |
| `templates/gitignore` | 가상환경, 패키지 폴더, `.env`, 캐시가 커밋되지 않게 막는 목록 |
| `skills/*/SKILL.md` | 필요할 때 부르는 작업 절차 4개 |
| `setup.sh` | 위 파일들을 제자리에 놓는 설치 스크립트 |
| `.gitattributes` | 줄바꿈을 LF로 고정해 리눅스에서 `setup.sh`가 깨지지 않게 함 |

## 스킬

`$이름`으로 부르거나 이름을 말하면 쓴다. 요청이 설명과 분명히 맞으면 Codex가 알아서 쓰기도 한다.

| 스킬 | 부르는 때 | 하는 일 |
|---|---|---|
| `interview-questions` | README를 읽은 뒤, 데이터를 본 뒤, 담당자 답을 받은 뒤 | 답에 따라 결과가 달라지는 질문 후보 3~5개, 담당자 답을 PLAN.md에 반영, 합의 확인 메시지 |
| `data-profile` | 데이터를 처음 다룰 때 | 형식 확인, 열별 빈 값·중복·이상값을 숫자로, 처리 전후 비교 기록 |
| `verify-before-done` | 단계를 끝낼 때 | 실제 실행으로 검증, 범위·보안 점검, 기록 갱신, 파일 지정 커밋 |
| `final-check` | 제출 준비를 시작할 때 | 제출물 대조, 결과와 한계 작성, 제출 후 질문 대비 요약 |

## AGENTS.md 규칙의 근거

`공식` = 응시 환경 공식 안내, `관찰` = 사전 체험 후기, `판단` = 작성자 판단.

| 규칙 | 근거 |
|---|---|
| README > 담당자 답 > 이 파일 | 공식: 과제 목표·필수 조건·제출물은 README 기준 |
| 요구사항에 없는 기능 금지 | 평가 도구 개발팀 인터뷰: 과잉 설계는 중점 감점 대상 |
| 실행 출력으로 검증, 실패하면 같은 검증으로 재확인 | 평가 도구 공개 자료의 충족 신호 |
| PLAN.md·DECISIONS.md 기록 | 판단. 평가 도구 데모 과제의 제출물에 DECISIONS.md가 있음 |
| push 금지 | 공식 |
| 커밋할 파일을 하나씩 지정 | 판단 |
| `python3` 사용 | 관찰: `python` 명령이 없었음 |
| 서버 0.0.0.0 바인딩 | 공식 |
| 1024 이상 포트 | 관찰: 1024 미만 포트는 거부됨 |
| 서버를 백그라운드로 실행 | 판단: Codex가 서버를 켜 둔 채 다음 작업을 이어 감 |
| Vite `allowedHosts` | 공개 키트 메모와 Vite 자체 보안 동작 |
| 설치가 막히면 표준 라이브러리 | 판단 |
| 개인 API 키 금지, 키·토큰 공개 금지 | 공식 |
| 키·토큰은 환경변수로 | 평가 도구 사이트의 채점 기준 문구 (구버전일 수 있음) |
| 화면 자동 조작, 설정 우회 금지 | 공식 |
